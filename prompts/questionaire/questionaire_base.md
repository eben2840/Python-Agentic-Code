Questionnaire activation rules:

Only treat a request as a questionnaire request when the user directly asks for a form, questionnaire, questionaire, or survey.

Direct requests include wording such as "create a form", "build a questionnaire", "make a survey", "generate an intake form", or "use a questionnaire".

Do not infer a questionnaire from requests for dashboards, summaries, lists, reports, views, tables, charts, patient overviews, or mini apps unless the user explicitly asks for a form/questionnaire/survey.
